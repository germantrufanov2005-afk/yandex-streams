# Яндекс Стримы — дашборд

GitHub Pages публикует `index.html` из ветки `main`. Файл
`yandex_streams_dashboard.html` — второй HTML-файл в репозитории; изменения
опубликованного дашборда вносятся в `index.html`.

## Проверка сводок

Показатели собственного канала находятся в `data/streams.json`. Источник —
[таблица команды](https://docs.google.com/spreadsheets/d/1Pg1Z9qwxsY-d92MkwxHC6nhbDk0q3SueC9DB816KtDo/edit?gid=1231339815),
лист `Статистика TWITCH ` (пробел в конце имени), сверка 23.10.2026.
`sheet_row` связывает запись с исходной строкой; `sheet_date` хранит дату
источника, `display_date` — сохранённую дату вкладки.

После обновления показателей:

```sh
python3 scripts/sync_statistics.py --write
python3 scripts/sync_statistics.py
python3 scripts/reconcile_dashboard.py --write
python3 scripts/reconcile_dashboard.py
```

Скрипт пересчитывает новые подписки в обзоре и тональность месячных сводок.
Августовская сводка относится только к семи эфирам Community Cast
13–23 августа, а не ко всему августу. При добавлении эфиров в август нужно
проверить границы этой выборки в скрипте.

В месячной сводке проценты взвешиваются по числу сообщений после фильтрации.
В обзоре показано среднее процентов по эфирам: каждый эфир имеет одинаковый
вес. Эфиры без массива комментариев не участвуют в обоих расчётах.
Исторические размеры выборок и доли приблизительные, поэтому итоговые доли
также обозначены как оценки. Точные количества по категориям нельзя
восстанавливать из округлённых процентов.

Просмотры, уникальные зрители, онлайн и прочие показатели стримов этот скрипт
не заменяет. Их нужно сверять с исходной статистикой.

## Обзор

`python3 scripts/render_overview.py --write` обновляет только обзор;
запуск без `--write` проверяет его соответствие данным.
После изменения показателей сначала запускайте `sync_statistics.py`,
затем `render_overview.py`, затем проверку `reconcile_dashboard.py`.

Обзор показывает пять основных показателей нашего канала, коллаборации
с августа, месячную динамику, лидеров по трём метрикам и историческую
тональность. В верхней карточке средний онлайн — среднее арифметическое средних
значений эфиров из исходной таблицы. На графике по месяцам средний онлайн
по-прежнему взвешивается по длительности. Часы просмотра рассчитываются
отдельно из минут просмотра. Общие просмотры коллабораций включают наш канал и относятся только
к эфирам с внесёнными просмотрами партнёров. Число партнёров — число разных
каналов в этой же выборке. Лучшие эфиры и столбцы динамики открывают
соответствующие существующие вкладки.

## Правила для новых анализов чата

- Сохранять исходный JSON TwitchDownloader и привязку каждого сообщения к его
  ID, времени и исходному тексту. Исходники чата и файлы с персональными
  идентификаторами не публиковать в этом репозитории.
- Сначала исключать бот-анонсы, команды, системные события, приветствия,
  ASCII-рисунки, сообщения только из эмоутов и повторяющийся бессодержательный
  флуд. Учитывать контекст, автора и время повтора. Для каждого исключения
  сохранять причину; одинаковые содержательные мнения разных людей не
  удалять автоматически.
- Не исключать сообщение только потому, что оно короткое. Например,
  «отличный эфир» и «звук ужасный» содержат оценку.
- Размечать общую тональность сообщения: позитив / нейтраль / негатив.
  Она включает реакции на гостей, игру, содержание и техническое качество
  эфира, а не только отношение к Яндексу. Мат сам по себе не определяет
  негатив. Сарказм и смешанные реакции проверять в контексте.
- Сохранять индивидуальную разметку, проверять неоднозначные сообщения.
  Проценты считать от реально размеченной выборки; количества категорий
  должны в сумме давать число сообщений после очистки. Отсутствующие данные
  не заменять нулём или выдуманной оценкой.
- Вкладку эфира, месячную сводку и обзор обновлять вместе. О проблемах с
  исходниками, расхождениях статистики и ограничениях анализа сообщать
  пользователю до публикации.

## Зрители и коллаборации

Обзор за весь период учитывает только канал Яндекса. Вкладки совместных
эфиров с августа сначала показывают общие карточки и показатели партнёров,
ниже — показатели канала Яндекса. Исторические карточки партнёров сохраняются
в `data/streams.json`; `scripts/sync_statistics.py` обновляет только наше
слагаемое просмотров и итоговую сумму. Редакционная обратная связь и анализ
чата при этом не меняются.

Сумму уникальных зрителей отдельных эфиров нельзя представлять как число
уникальных людей за весь период. Пока нет дедупликации, корректная подпись:
«Сумма уникальных зрителей по эфирам; возможны повторные зрители».
Тот же принцип применяется к пересечению аудиторий партнёрских каналов.
Сумма пиков разных каналов не является одновременным общим пиком.
Средний онлайн за период требует взвешивания по длительности; для общего
онлайна коллабораций нужен одинаковый временной интервал.
